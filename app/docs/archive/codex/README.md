# Historical agent state

The state, task queue, decisions, and validation records in this directory preserve earlier hardening work. Their structure is covered by recovery-state tests and is preserved under `docs/archive/codex/` (formerly `.codex/`).

For current work, read [AGENTS.md](../../../../AGENTS.md) and the [agent README](../../agent/README.md). Resolve the actual branch, HEAD, CI, and release status from Git/GitHub. Old task states and validation claims do not authorize new work or prove a new version is accepted. Historical references to root reports are mapped in [the archive index](../README.md).
