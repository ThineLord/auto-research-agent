# Auto Research Agent 0.2.2

[English](0.2.2.md) · [简体中文](0.2.2.zh-CN.md)

A maintenance release that makes the repository easier to browse. The root now has **17 tracked entries instead of 22**. Each homepage shows one actual dashboard screenshot in its own language and a compact navigation table.

## Organization and upgrade

| Previous location | New location / command |
| --- | --- |
| `.codex/` | [Historical agent records](../archive/codex/README.md) |
| `browser_tests/` | `tests/browser/`; keep using `make browser-test` |
| `requirements/` | [scripts/dependencies/](../../scripts/dependencies/README.md) |
| `pip install -r requirements.txt` | `make install-dev` |
| `.env.example` | Removed; the optional legacy UI variable is described in the [development guide](../reference/development.md) |

Pull the release and run `make install-dev` (or `make install` for application use). Scripts that reference the old dependency/test paths should use the table above. Historical record contents retain their original path references; current instructions are in [AGENTS.md](../../../AGENTS.md).

## Compatibility and validation

Runtime configuration, prompts, research project locations and saved-artifact formats are unchanged. Dependency pins are unchanged. CI, wheel checks and source environment fingerprints use the new constraints path. Default Python tests remain separate from optional Chromium/WebKit tests.

Release checks cover `make check`, an isolated wheel installation and both browser engines. The two screenshots show the existing dashboard with a public synthetic task; this maintenance release makes no new model-quality or real-provider validation claim. The CLI remains available as a wheel; the dashboard requires a source checkout.
