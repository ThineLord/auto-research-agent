# Auto Research Agent 0.3.0

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md)

程序工程文件统一收进 `app/`，公开 `example/` 和新建研究目录与其同级。运行 `./start` 并打开输出的本地网址，在现有选择器旁点击 **+** 即可新建；切换无需重启，重启后保留上次选择。

## 兼容边界

本次次版本更新调整源码安装路径和开发命令：元数据在 `app/pyproject.toml`，环境在 `app/.venv/`，内部命令从 `app/` 执行。根目录 `make` 命令继续转发。wheel 仍仅提供 CLI，以当前目录作为工作区；首次 Mock 在工作区直接创建 `example/`。CLI 和网页服务均支持 `--workspace` 指定工作区。

旧 `projects/<name>/` 原位兼容，同名时优先旧项目；旧项目无效时不静默替换为另一个目录。原数据、检查点身份和产物格式不自动迁移。本次不提供搬迁工具，因为搬动检查点不能简化为文件复制。升级前阅读[升级与回滚指南](../user/workspace-upgrade.zh-CN.md)。旧 0.2.x 无法发现新建的同级研究目录。

## 验收与限制

验收覆盖首次启动、双项目创建／保存／切换／重启、新旧结构 Mock、历史检查点续跑、CLI、wheel、隐私白名单及两种浏览器引擎。流程测试使用本地模拟服务，不调用付费模型或 Cloud Bots。历史回归使用真实 v0.2.2 程序生成模拟运行，再在原路径由新版恢复；此项需要 v0.2.2 标签，CI 会获取历史。

不扩展科研能力、模型政策或重做 UI。旧环境和遗留目录不会自动删除。`start` 是 Bash 启动脚本；Windows 可在兼容 shell 下使用 `make ui`，或在已安装依赖的 `app/` 中执行 `python -m ui.server`。本次验证环境为本地 macOS 与 Linux CI，不包含原生 Windows。
