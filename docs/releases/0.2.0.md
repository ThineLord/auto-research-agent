# Auto Research Agent 0.2.0

Release date: **2026-11-09**
[English](0.2.0.md) · [简体中文](0.2.0.zh-CN.md) · [Changelog](../../CHANGELOG.md)

## What changed

This release provides a clear entry point and a consistent version boundary for the existing research application.

- A short English homepage and a separate Chinese homepage introduce the project, local startup, file layout, and documentation.
- Users and agents each have their own English and Chinese README. Codex manages the work; subagents review and perform authorized merges, without external bots.
- Detailed guides move to `docs/reference/`, design records to `docs/design/`, and historical root reports to `docs/archive/`. A documentation map and path migration index preserve access to the details.
- Package metadata, release notes, changelog, and tag naming now agree on 0.2.0. Local/CI checks detect version drift, missing bilingual release notes, and broken relative file links in maintained documentation.
- Local browser captures and `output/` are explicitly ignored by Git.

The baseline also includes the previously merged local dashboard, system-aware persistent appearance, navigation, and performance/recovery improvements. See the [changelog](../../CHANGELOG.md) for the boundary; this reorganization does not introduce a new research algorithm.

## Upgrade

Stop active runs and back up private project data and local configuration, including external run storage if configured. Keep local edits before switching to `v0.2.0`; then run `make install` and `make ui` from the repository root. Reuse existing configuration instead of copying over it.

Runtime directories, prompts, scoring semantics, provider behavior, checkpoint formats, and saved-artifact schemas are unchanged. No research-data migration is required. Old documentation paths have a [migration index](../archive/README.md). Historical tags are preserved.

## Validation and scope

Release acceptance requires `make check`, an isolated wheel install with provider-free mock execution, independent subagent review, and Python 3.10/3.13 CI for the final PR and merged commit. The published GitHub Release records the completed checks and exact commit; these source notes describe the required checks, not an unperformed result.

This release does not establish fresh live Ollama/Gemini availability, research correctness, or current free-tier pricing. The dashboard runs from a source checkout; the wheel provides the CLI and bundled starter resources. Distribution is a GitHub source release, with no PyPI publication or private project assets.

Future updates follow the [version policy](../agent/releases.md).
