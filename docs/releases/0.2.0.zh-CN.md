# Auto Research Agent 0.2.0

发布日期：**2026-11-09**
[English](0.2.0.md) · [简体中文](0.2.0.zh-CN.md) · [变更记录](../../CHANGELOG.md)

## 更新内容

本次发布为现有研究程序提供清楚的入口和统一的版本边界。

- 英文与中文首页分开，简明介绍项目、启动方式、文件位置和文档入口。
- 用户和 Agent 各有独立的中英文 README。Codex 负责管理，由 subagents review 并执行已授权的合并，不调用外部 bots。
- 详细指南移入 `docs/reference/`，设计记录移入 `docs/design/`，历史根目录报告移入 `docs/archive/`，通过文档导航和路径索引保留访问入口。
- 包元数据、版本说明、变更记录和标签命名统一为 0.2.0。本地和 CI 检查版本漂移、中英文版本说明缺失以及维护文档中的相对文件链接失效。
- Git 明确忽略本地浏览器截图目录和 `output/`。

版本基线也包含此前已合并的本地工作台、跟随系统且持久保存的外观、页面导航，以及性能和恢复改进。具体边界见[变更记录](../../CHANGELOG.md)；本次整理没有引入新的研究算法。

## 升级方式

停止活动运行，备份私人项目、本地配置，以及配置过的外部运行存储。保留本地修改后切换到 `v0.2.0`，在仓库根目录执行 `make install` 和 `make ui`。复用原有配置，不要用示例覆盖。

运行目录、提示词、评分语义、模型调用行为、检查点和产物结构保持不变，无需迁移研究数据。旧文档位置可通过[路径索引](../archive/README.md)查找。历史标签保留。

## 验证与范围

发布验收要求：`make check`、隔离 wheel 安装及不调用模型的 mock 验证、独立 subagent review，以及最终 PR 和合并提交的 Python 3.10/3.13 CI。GitHub Release 会记录实际完成的检查和准确提交；本说明列出验收要求，不把尚未执行的检查写成结果。

本次不验证新的 Ollama/Gemini 在线可用性、研究结论正确性或最新免费额度。网页工作台通过源码仓库运行；wheel 提供命令行程序和入门资源。本次发布 GitHub 源码版本，不发布到 PyPI，也不上传私人研究资产。

后续更新遵循[版本规则](../agent/releases.zh-CN.md)。
