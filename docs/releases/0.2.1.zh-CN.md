## 本次更新

本维护版本完成了 0.2.0 验收报告中的全部五项 P1–P2 改进。

| 优先级 | 改进 | 实际变化 |
| --- | --- | --- |
| P1 | 输入保存保护 | 仅提交改动字段，在项目锁内核对字段版本。只修改任务不会覆盖后台更新的记忆；冲突时保留草稿，明确选择最新内容或替换。网页和旧版 Streamlit 编辑器均受保护。 |
| P2 | Ollama 地址一致 | 模型发现、启动预检和生成统一使用 `ollama_base_url`，不再被本地 CLI 默认地址或 `OLLAMA_HOST` 干扰。 |
| P2 | 评分校验 | 新 Judge 输出必须包含完整的五项分数（上限 25/25/20/20/10）及等于分项之和的 0–100 总分。无效评分按失败处理，不能提升最佳输出；正常和诊断模式共用“先分项、后求和”的提示及算式示例，减少总分不一致。 |
| P2 | 浏览器回归 | Chromium 与 WebKit CI 在隔离环境中运行真实网页和 CLI，覆盖双窗口冲突、聚焦／展开编辑器后台刷新、停止续跑、输出、分析及语言持久化。 |
| P2 | 环境记录与依赖锁定 | 源码安装、CI 和 wheel 检查使用版本依赖约束；运行记录保存实际应用、Python、直接依赖版本及可选 Ollama 摘要。续跑单独记录当次环境，旧记录缺失的初始环境保持未知。 |

功能 PR：[#17](https://github.com/ThineLord/auto-research-agent/pull/17)、[#18](https://github.com/ThineLord/auto-research-agent/pull/18)、[#19](https://github.com/ThineLord/auto-research-agent/pull/19)、[#20](https://github.com/ThineLord/auto-research-agent/pull/20)、[#21](https://github.com/ThineLord/auto-research-agent/pull/21)、[#23](https://github.com/ThineLord/auto-research-agent/pull/23)、[#24](https://github.com/ThineLord/auto-research-agent/pull/24)。Codex 负责实现；独立 subagents 审查并执行已授权的合并。

最终浏览器验收还发现并修复了 Draft 前的停止时序问题：停止请求恰好在新轮次建立后到达时，现在会将该次尝试标记为停止，保留可续跑检查点，不虚增已完成轮次。第 1／2 轮确定性回归测试在旧行为下失败，修复后通过。

## 升级和兼容性

停止正在运行的任务，保留本地修改并备份私人项目和配置。将干净的检出切换至 `v0.2.1`，运行 `make install`，重启工作台并刷新已打开的浏览器标签页。继续使用已有 `config.yaml`，不要用示例覆盖它。

运行路径和已有检查点保持原位；环境字段为增量添加，不需要迁移研究数据。历史评分仍可读取，新模型响应须符合严格评分规则；不合格的响应会显示评分失败，不会生成虚假分数。自定义 Judge 提示词须遵循共同规则。

固定依赖安装见[依赖约束说明](../../scripts/dependencies/README.md)。源码检出可记录约束文件指纹；wheel 环境无法取得该文件时记录 null。这些记录不保证模型输出确定性复现。wheel 提供 CLI，网页工作台需要源码检出。

## 验证及边界

功能验收已通过 656 项 Python 测试、1669 个子测试、隔离 wheel 安装与离线模拟运行，以及 Chromium、WebKit 各四项真实浏览器场景。正式发布还要求最终版本完整检查、独立审查，以及 PR 和合并提交上的 Python 3.10/3.13 与浏览器 CI 成功；GitHub Release 记录最终验证结果和提交。

本地 `llama3.1:8b` 合成任务诊断已完成全部四阶段，无 Agent 错误，总分 80 与分项一致；在真实产物上通过网页仅修改任务后，记忆逐字节保持不变。此前一次 `qwen3:8b` 在 Review 超时；此前 Llama 返回总分 90、分项和 80 时被正确拒绝，随后加入了先分项后求和的提示改进。这些是本机验收观察，不代表模型质量保证。

浏览器自动化使用合成输入和本地模拟服务。WebKit 测试不等于原生 Safari 认证。真实服务可用性与模型输出质量取决于环境；发布说明会单独区分本地模型实测和模拟测试。本次升级没有调用 Gemini，没有发布至 PyPI，也不包含私人研究产物。
