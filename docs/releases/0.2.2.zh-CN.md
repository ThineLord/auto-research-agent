## 整理与升级

| 原位置 | 新位置／命令 |
| --- | --- |
| `.codex/` | [历史 Agent 记录](../archive/codex/README.md) |

拉取新版本后执行 `make install-dev`（仅使用应用时执行 `make install`）。自定义脚本若引用旧依赖或测试路径，请按上表更新。历史记录正文保留原路径；当前维护规则以 [AGENTS.md](../../AGENTS.md) 为准。

## 兼容性与验证

运行配置、提示词、研究项目位置和成果格式保持不变，依赖版本没有变动。CI、wheel 检查和源码环境指纹已改用新约束路径。默认 Python 测试仍与可选的 Chromium／WebKit 测试分开。

发布检查覆盖 `make check`、隔离 wheel 安装及两种浏览器引擎。两张截图展示现有工作台和公开演示任务；本次维护不增加模型质量或真实模型验证声明。wheel 继续提供 CLI，网页工作台需要源码仓库。
